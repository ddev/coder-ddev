This workspace is set up for web development with DDEV.

Quick start (your project can live in any directory):
  git clone <repo-url> <yourdir> && cd <yourdir>
  ddev config --project-type=<type>
  ddev coder-setup
  ddev start

📚 Documentation: https://github.com/ddev/coder-ddev
