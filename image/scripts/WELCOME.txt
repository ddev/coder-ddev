This workspace is set up for web development with DDEV.

Quick start:
  git clone <repo-url> <project-name>   # use a registered project name
  cd <project-name>
  ddev config --project-name=<project-name> --project-type=<type>
  ddev coder-setup
  ddev start

⚠️  The DDEV project name must match a name registered in the workspace.
   Registered names are shown in the startup log and in CODER_PROJECT_NAMES.
   To add more projects, edit the workspace and update "DDEV project names".

📚 Documentation: https://github.com/ddev/coder-ddev
