# DDEV Coder Workspaces

[coder.ddev.com](https://coder.ddev.com) gives you a complete [DDEV](https://ddev.com) development environment in your browser. Each workspace is its own Linux machine with Docker, DDEV, Git, Node.js, Composer and VS Code for Web already set up. You don't need to install anything on your computer.

<div class="grid cards" markdown>

- :material-shape-plus: **[Freeform workspaces](freeform/index.md)**

    ---

## Start a workspace

| I want to…                                           | Go to                                                                                              |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Work on a drupal.org issue or contrib project        | [Drupal issue picker](https://start.coder.ddev.com/drupal-issue)                                    |
| Run my own project, or several projects at once      | [Create a freeform workspace](https://coder.ddev.com/templates/coder/freeform/workspace?mode=manual) |
| Get a clean Drupal core checkout with no issue fork  | [Guided Drupal core](https://start.coder.ddev.com/drupal-core)                                      |

Not sure which one? See [Choosing a template](getting-started/choosing-a-template.md).

## Get help

- [Troubleshooting](workspaces/troubleshooting.md) covers the most common problems.
- Report bugs or ask for features in [ddev/coder-ddev issues](https://github.com/ddev/coder-ddev/issues).
- Chat with us in the [DDEV Discord](https://ddev.com/s/discord) or in **#ddev** on Drupal Slack.

!!! note "Running your own Coder server?"
    These docs are written for people using the hosted service at coder.ddev.com. If you want to run these templates on your own infrastructure, see [Self-Hosting](self-hosting/overview.md).
